# Security Policy

## Supported version

Security fixes are applied to the latest code on `master`. No older release
branches are currently maintained.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue for a suspected vulnerability or attach
private diagrams, credentials, or personal data to an issue.

Include the affected workflow, reproduction steps, impact, and any suggested
mitigation. A maintainer will acknowledge a valid report and coordinate a fix
and disclosure timeline.

The application is client-only, but browser storage, share links, clipboard
operations, imported backups, SVG rendering, and exported files remain part of
its security boundary.
